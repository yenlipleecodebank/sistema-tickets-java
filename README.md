Sistema de Gestión de Tickets en Línea

Este proyecto es una aplicación Java de línea de comandos (CLI) desarrollada para la materia de **Estructuras de Datos** en la **Universidad CENFOTEC**. El sistema simula el ciclo de vida completo de un ticket de soporte mediante roles de Usuario y Administrador.
